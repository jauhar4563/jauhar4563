# Technology icon sources

Devicon SVGs: https://github.com/devicons/devicon/tree/32fe1d3b3f36ad11f90ab94f7db59738139c2bf6/icons (MIT; see DEVICON-LICENSE.txt).

Pydantic and MLflow: https://github.com/simple-icons/simple-icons/tree/90646e4bf7f3b89df6c37e65baf3e7bc759a517c/icons (CC0; see SIMPLE-ICONS-LICENSE.txt).

OpenAI: https://github.com/simple-icons/simple-icons/blob/14.0.0/icons/openai.svg (CC0).

Badge generation embeds these SVGs locally. Selected dark monochrome fills are adapted for contrast on the midnight background. HTML/CSS combines both technology marks; Azure OpenAI uses the Azure mark, AWS S3 uses the AWS provider mark, and SQL uses an original generic database symbol. Product marks identify technologies only.
